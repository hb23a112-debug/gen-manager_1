# Gen Manager — ComfyUI の生成結果を、ギャラリーで管理する

ComfyUI の左サイドバーに **「生成管理」タブ**を追加するカスタムノード(拡張機能)です。
`output` フォルダの画像・動画・音声を **日付ごと**に並べ、**お気に入り・タグ・メモ・条件**を付けて選び出せます。
画像をクリックすると、**生成設定(プロンプト・モデル・LoRA・サンプラー)と所要時間**が確認できます。
生成するたびに設定や所要時間が**自動で記録**されるので、コマンドや設定ファイルは不要です。

- **日付ごとの表示**(新しい順)と、**種類**(png / jpg / mp4 / mp3 …)・**日付範囲**・**条件**・**タグ**・**お気に入りのみ**での絞り込み
- ★ でお気に入り登録。タグとメモも付けられる
- **条件**: 「lora=0.6」のようなラベルを付けて、設定違いの画像を見比べる(生成前に決めておくことも、あとから付けることもできる)
- **過去分の取り込み**: 設定の埋め込まれた PNG を、あとから登録
- ComfyUI の再起動ボタン(ComfyUI-Manager が必要)

**画像ファイルは移動・変更・削除しません。** 管理情報は `output/_gen_tracker/` に分けて保存します。

## インストール

1. ComfyUI の `custom_nodes` フォルダを開きます。
2. このリポジトリを置きます(どちらか)。
   - Git が使える場合: `custom_nodes` で `git clone https://github.com/<あなたのユーザー名>/gen-manager`
   - ZIP の場合: 「Code → Download ZIP」で取得して解凍し、`custom_nodes/gen-manager/` に置く
     (**`custom_nodes/gen-manager/__init__.py` が直下に来る**ようにします。フォルダが二重にならないよう注意)
3. ComfyUI を再起動します。
4. 左サイドバーに、画像アイコン(**生成管理**)が増えていれば完了です。

追加の `pip install` は不要です(ComfyUI 本体が持つ `aiohttp` と、生成設定の読み取りに使う `Pillow` のみ)。

## 使い方

1. サイドバーの **生成管理** を開きます。output の画像が日付ごとに並びます。
2. カードの **☆** でお気に入り登録。**画像をクリック**すると、生成設定・所要時間・タグ・メモ・条件の確認と編集ができます。
3. 上の「**いまの条件**」に名前(例: `lora=0.6`)を入れてから生成すると、その生成にその条件が付きます。
   条件を変えながら生成し、**条件**の絞り込みで見比べられます。空のままなら、モデル名から自動で付きます。
4. 過去に作った画像は、⚙ → **過去分を取り込む**で登録できます(設定が埋め込まれた PNG のみ。生成時間は過去分には残っていないため空です)。
   取り込まなくても、画像のクリックで生成設定は見られます。

ポイント:
- 条件は **Queue を押した時点のもの**で記録されます(連続で Queue しながら条件を変えても混ざりません)。
- 条件は「生成」に付くため、**1回の生成で複数枚できた場合は、全部の画像に同じ条件**が付きます。
- 生成の記録は、ComfyUI を開いたままなら **10秒おき**に自動で取り込まれます。生成完了時にも即時に取り込みます。
- jpg・動画・音声や、設定のない画像にも、あとから条件・タグ・メモ・お気に入りを付けられます(生成設定の表示は PNG のみ)。
- 画像が数千枚あっても重くならないよう、400件ずつ表示します(下の「さらに表示」で続き)。

## よくある質問

**記録はどこにありますか?** `ComfyUI/output/_gen_tracker/` に `gen_manager.db`(記録・お気に入り・タグ・メモ)と `settings.json`(設定)があります。バックアップはこのフォルダをコピーするだけです。

**favorite_gallery のお気に入りは引き継がれますか?** 引き継がれません。お気に入り・タグ・メモの保存先が別です(`favorites.json` は削除されずに残ります)。両方を入れても、タブは別々に動きます。

**生成時間や失敗の一覧、条件ごとの成功率の比較は?** 画面にはありません(失敗した生成は画像が無いため、ギャラリーには出ません)。記録は残っているので、コマンドライン版で見られます。
```bash
python gen_manager.py --root "C:\ComfyUI\output\_gen_tracker" list --status failed
python gen_manager.py --root "C:\ComfyUI\output\_gen_tracker" compare -e ComfyUI
```
詳しくは [docs/CLI.md](docs/CLI.md)。

**アンインストールは?** `custom_nodes/gen-manager` を削除します。記録(`_gen_tracker`)は残るので、不要なら一緒に削除してください。

**画像を移動・名前変更したら?** 画像そのものはギャラリーに新しい場所で出ますが、お気に入り・タグ・メモ・条件は古いパスに付いたままです。

**何も表示されません。** ComfyUI の起動ログに `[GenManager] 読み込みました` が出ているか、ブラウザの F12 コンソールにエラーが出ていないかを確認してください。

## 制限

- 記録できるのは、ComfyUI の実行履歴に残る **output に保存された出力**です(プレビュー用の temp 出力は対象外)。
- 設定の読み取りは、標準的な `KSampler` 系の構成が前提です。独自ノードで組んだ構成では、一部の設定が空になることがあります
  (プロンプトは「その他」の欄に、ノード名付きでまとめて表示されます)。
- ComfyUI の実行履歴は再起動で消えます。ComfyUI を終了している間の生成は記録できません。
- 古い ComfyUI では、成功時の所要時間が取れないことがあります。
- 全部キャッシュで新しい出力が無かった実行は、記録しません。
- 作成日時は OS 依存の近似値です(`st_birthtime`、無ければ `st_ctime` と `st_mtime` の古い方)。
- 再起動ボタンは ComfyUI-Manager の `/manager/reboot` を呼びます。ComfyUI Desktop では効かない場合があります。

## 構成とテスト

```
gen-manager/
├── __init__.py          ComfyUI との接続(HTTPルート・自動同期)
├── tracker.py           実行履歴 → 記録 への変換、ギャラリー用の一覧、生成情報の解析
├── gen_manager.py       記録の中核(SQLite)+ コマンドライン版
├── web/gen_tracker.js   サイドバーの画面
└── tests/               自動テスト
```

追加するエンドポイント: `GET /gen_tracker/files`(一覧)、`POST /gen_tracker/file_update`(お気に入り・タグ・メモ・条件)、
`GET /gen_tracker/file_info`(PNG の生成情報)、`POST /gen_tracker/sync` / `ingest` / `settings`、`GET /gen_tracker/state`。
クライアントから受け取ったパスは、すべて検証します(絶対パス・`..`・output の外・シンボリックリンク経由・対象外の拡張子を拒否)。
プロンプトなど画像由来の文字列は、`textContent` だけで表示し、HTML として解釈しません。

```bash
pip install pillow aiohttp
python -m unittest discover -s tests -v
```

**テストしていない範囲:** 実際の ComfyUI 本体の上での動作確認(実行履歴の形式や拡張の読み込みは、ComfyUI の仕様に基づいて作っています)。
画面は、ComfyUI を模した最小の土台と実際のバックエンド処理を使い、ブラウザ(Chromium)でギャラリーの全操作を確認しています。
